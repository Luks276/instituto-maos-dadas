# Histórico de alterações

As versões seguem o formato SemVer `MAJOR.MINOR.PATCH`: `MAJOR` para mudanças incompatíveis, `MINOR` para funcionalidades compatíveis e `PATCH` para correções compatíveis.

## Não lançado

- Adicionado Vite para desenvolvimento local e build multipágina de produção.
- Preparado workflow de GitHub Actions para build e deploy de releases no GitHub Pages.
- Próximas alterações serão registradas aqui antes de uma nova release.

## [0.1.0] - 2026-10-01

### Adicionado

- Estrutura separada para HTML, CSS, imagens e JavaScript.
- Navegação SPA com suporte ao histórico do navegador.
- Cartões de projetos gerados por template HTML.
- Validação do formulário e histórico local de participação.
- Organização do JavaScript em módulos ES6.
